# Relationship and company logos

Save approved logos here as SVG (preferred) or PNG, using these names:
`vivo-energy.svg`, `air-arabia.svg`, `uganda-airlines.svg`, `mtn.svg`, `kenfields.svg`.

A logo appears on the site only when `logoApproved: true` is set for that entry in `/content/partners.ts`.
Until then the name is shown in serif type. Use written permission from each trademark owner before enabling.
